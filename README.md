# AWS Security Builder – Securing and Monitoring Resources

## Project Overview

This project demonstrates the implementation of security controls, monitoring, and logging capabilities within AWS. The lab focuses on securing Amazon S3 resources, monitoring activity through logs and analytics, and implementing network security controls within Amazon VPC environments.

The project was completed as part of an AWS Security learning initiative and includes hands-on implementation of cloud security best practices.

---

## Objectives

* Secure Amazon S3 buckets using bucket policies
* Enable S3 Versioning for data protection
* Configure S3 Server Access Logging
* Implement S3 Inventory reporting
* Query S3 access logs using Amazon Athena
* Configure and analyze VPC Flow Logs
* Secure EC2 instances using Security Groups
* Implement Network ACLs
* Create and configure AWS Network Firewall
* Review and secure VPC networking components

## Project Architecture

### Phase 1 – Securing Amazon S3

* Created S3 buckets
* Applied bucket policies
* Tested access controls
* Enabled Versioning
* Enabled Server Access Logging
* Configured S3 Inventory
* Queried access logs using Athena

### Phase 2 – Securing VPC Resources

* Reviewed VPC architecture
* Created VPC Flow Logs
* Monitored network traffic in CloudWatch
* Modified route tables
* Configured Security Groups
* Implemented Network ACLs
* Deployed AWS Network Firewall
* Validated traffic filtering and network security controls
